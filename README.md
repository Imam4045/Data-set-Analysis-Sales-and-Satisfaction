# 📊 Dataset Analysis: Sales and Satisfaction

A Python-based analysis of a 10,000-row Sales and Customer Satisfaction dataset.
This project analyzes Control vs. Treatment groups, sales, customer satisfaction, purchase behavior, data distributions, correlations, and categorical encoding.
